# Employee Tracking System

## Overview
The Employee Tracking System is a web application designed to manage and monitor employee information efficiently. It enables organizations to maintain employee records, track attendance, and manage employee-related data through a simple and user-friendly interface.

## Features
- Employee registration and management
- Add, update, and delete employee records
- Employee attendance tracking
- Search and filter employee details
- Responsive and user-friendly interface

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Database: JSON (agent_cache.json)

## Installation

1. Clone the repository

```bash
git clone https://github.com/MadhanKumarU/Employee-tracking.git
```

2. Navigate to the project directory

```bash
cd Employee-tracking
```

3. Install the required Python packages

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python main.py
```
